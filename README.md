# react-native-ios-controls

Control Center, Lock Screen and Action Button controls for React Native — iOS 18 ControlWidget bridged with state sync, press handling and a setup CLI

## Installation


```sh
npm install react-native-ios-controls
```


## Usage


```js
import { multiply } from 'react-native-ios-controls';

// ...

const result = multiply(3, 7);
```
